## Agent skills

### Issue tracker

Issues are tracked in GitHub Issues on CRIIPI11/rn-watch-connect, using the `gh` CLI. See `docs/agents/issue-tracker.md`.

### Triage labels

Uses `needs-maintainer`, `needs-info`, `ready-for-agent`, `ready-for-human` and `wontfix` (the default vocabulary, with `needs-triage` renamed to `needs-maintainer`). See `docs/agents/triage-labels.md`.

### Domain docs

Single-context: one `GLOSSARY.md` and `docs/adr/` at the repo root. See `docs/agents/domain.md`.
